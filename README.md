# k8s-monitoring-stack
Personal Kubernetes monitoring lab with Prometheus, Grafana and Loki. Learning observability, Helm and cloud-native operations.
# Kubernetes Monitoring Stack

## Overview

Containerized monitoring and logging platform deployed on Kubernetes.

The stack provides centralized observability through metrics collection, dashboards and log aggregation.

## Stack

- Kubernetes
- Helm
- Prometheus
- Grafana
- Loki

## Features

- Infrastructure monitoring
- Application monitoring
- Centralized logging
- Metrics collection
- Dashboard visualization

## Architecture

Prometheus collects metrics from Kubernetes workloads and infrastructure.

Grafana provides dashboards and visualization.

Loki centralizes logs generated by applications and Kubernetes components.
